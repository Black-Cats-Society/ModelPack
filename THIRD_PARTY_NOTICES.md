# Third-party attribution

## Fast Draft 0.1.3

The user-supplied `FastDraft-0.1.3-maya2025.zip` provides the surface-drawing
engine bundled under `model_pack_draft`. The original module docstrings are
retained. This integration gives it an independent Maya context name, live
section changes for cylinders, surface-normal depth gestures and an explicit
blue/teal viewport overlay matching Maya's active toolbar buttons.
The Model Pack cap-history node and T menu add editable cylinder cap topology
and selective smoothing while retaining the bundled Fast Draft drawing engine.
The compact Model Pack host is in `model_pack_fast_draft.py`; the standalone
Fast Draft window and installer are not required.
