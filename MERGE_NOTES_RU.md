# Объединённая версия 0.1.151

Основа сравнения: ModelPack_0.1.82.zip. Взяты актуальные локальные доработки и изменения из ModelPack_0.1.151_Windows_Maya2025_2027_Handoff.zip.

Сохранены наши группы панели, компактные кнопки, заголовок, пользовательские иконки и названия One Slide / Two Slide / Floater Liner; Control Curve, Curve Mesh, Floater Fit, угловое сокращение Reset Tube, исправления Path, история и защита при изменениях сцены.

Перенесены обновления Bevel (опорные ряды и движение по нормалям), ExtrudeX/Inset с бинарными модулями, Crease, Curve Editor, Floater Pattern, Make Planar, Clean History и Intersect Curve, а также совместимые исправления геометрии. Новые кнопки добавлены в существующие группы, без замены оформления.

Offset: сохранена наша трактовка Variation (0% полный Offset, 100% исходная форма), без Create N-gons; объединена обработка изогнутой области и удаление обратной грани открытого плоского полигона.

Проверено в Maya 2027, отдельные тестовые сцены и настройки:
- 4 проверки поставки: Bevel support spacing, ExtrudeX internal inset, open border binary, manifest.
- 56 регрессионных тестов Mirror / Reset Tube / Selection. Для проверки маршрутизации Qt тестовый viewport показывается: новая реализация намеренно исключает скрытые окна.
- 6 тестов истории Reset Tube.
- Проверка сброса активных инструментов при изменении сцены.
- Проверка Offset, нормалей, Undo/Redo и всех 32 кнопок панели.

Maya 2025 здесь не установлена; бинарные файлы для неё сохранены из поставки, но локально не запускались. Проверки offscreen не заменяют проверку жестов и визуального поведения в рабочем viewport.
