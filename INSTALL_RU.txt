Model Pack 0.1.0-beta — установка
================================

Проверенная среда: Windows / Autodesk Maya 2027.
Python, PySide6, shiboken6 и NumPy используются из Maya.

1. Полностью распакуйте ZIP в постоянную папку с латинским путём,
   например C:/MayaTools. Пробелы в пути допустимы.
2. Откройте Maya и выберите вкладку Shelf.
3. Перетащите install_model_pack.py из распакованной папки в 3D viewport.
4. Появится кнопка MP и откроется панель Model Pack.
5. В меню Shelf выберите Save All Shelves.

Не перемещайте папку после установки. Установщик запоминает её путь.
Файлы пакета остаются в ней; icons и все Python-модули должны быть рядом.
Также создаётся maya/modules/ModelPack.mod для загрузки узлов после перезапуска.
Путь с кириллицей не поддерживается загрузчиком узлов Maya при открытии сцен.
Установщик проверяет это до записи файлов и создания кнопки.

Если перетаскивание не работает, в Script Editor → Python выполните:

    import runpy
    runpy.run_path(r'C:\MayaTools\ModelPack_0.1.0-beta\install_model_pack.py', run_name='__main__')

Замените путь своей папкой.

Обновление: сохраните сцену, закройте Maya, замените весь комплект.
Если путь изменился, повторите установку на той же полке и сохраните Shelf.
Повторная установка обновляет существующую кнопку MP без дубля.

Удаление: удалите кнопку MP и сохраните Shelf. Закройте Maya, удалите
ModelPack.mod из пользовательской maya/modules и папку пакета.
До удаления примените узлы Model Pack, которые нужны в сохранённых сценах.

Полная инструкция, описание инструментов и решение ошибок — в README.md.
