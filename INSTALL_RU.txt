Model Pack + ReCurve + Fast Draft 0.1.152-beta

1. Распакуйте весь архив в постоянную папку с латинским путём,
   например C:/MayaTools/ModelPack_ReCurve.
2. В Maya выберите вкладку Shelf.
3. Перетащите install_model_pack.py из распакованной папки в 3D-окно Maya.
4. Сохраните Shelf: Shelf > Save All Shelves.

Кнопка MP обновится. Отдельно устанавливать Fast Draft не требуется.
При переносе папки повторите установку.

FAST DRAFT
Нажмите Fast Draft внизу Model Pack и выберите Cylinder или Cube.
ЛКМ с перетаскиванием по мешу — нарисовать основание, затем отпустить.
Второе перетаскивание по направлению от поверхности — добавить примитив;
внутрь меша — вырезать. Направление определяется нормалью грани.
При взгляде прямо на грань: вверх — добавить, вниз — вырезать.
Отпускание применяет операцию. Ctrl+Z / Ctrl+Y — обычная отмена / повтор.

Shift + колесо — изменить число сторон Cylinder без сброса текущего рисунка:
3–256 сторон (по умолчанию 32). Число запоминается. Ползунков нет.
Cube всегда имеет шесть граней, без сечений и действий с Shift.
Если рисунок ещё не начат, меняется настройка следующего примитива.

Esc — отменить незавершённый рисунок и остаться в инструменте.
Q, повторное нажатие Fast Draft или другой инструмент — выйти.
Смена формы отменяет незавершённый рисунок.
Контур явно бирюзовый (#00CCCC) при рисовании основания и глубины.
Кнопка Fast Draft имеет обычную ширину одной кнопки Model Pack.

ЦИЛИНДРЫ: СГЛАЖИВАНИЕ И КРЫШКИ
Боковые рёбра цилиндра — soft; границы крышек — hard.
У созданного цилиндра в Channel Box доступны Radius, Height, Sides, Top Cap.
Выделите его и нажмите T в 3D-окне при открытом Model Pack:
  Cap — цельная крышка без центральной точки (по умолчанию).
  Center — веер треугольников с одной центральной точкой.
  Parallel — параллельные соединения вершин обода, без новой точки в центре.
Нижняя крышка остаётся цельным N-gon. Смена режима поддерживает Undo/Redo.
Параметры сохраняются в сцене; Channel Box работает и после закрытия Model Pack.
Для других объектов и при вводе текста обычная клавиша T сохраняется.

При вычитании цилиндр всегда без центральных точек. Стенки выреза — soft,
дно глухого выреза — N-gon без веера к центру. История создания сохраняется
у добавленных цилиндров, чтобы Top Cap можно было изменить позже.

ReSegments и Control Curve остаются на месте со своими сочетаниями клавиш.
Описание проверок: VALIDATION.md.
